# Glossary

Source: Roadmap Version 2.0, Part 27. Abbreviations are allowed in code only when they are an industry standard listed here.

| Term | Meaning |
|------|---------|
| Bill of Quantities | The list of all work items with planned quantity, unit and rate. |
| Running Account Bill | An interim bill for work completed so far, used to request payment during a project. |
| Payment claim | The document a contractor sends to a client to request payment. |
| Measurement sheet | The record of measured quantities of completed work. |
| Retention | A portion of payment held back by the client until the work is complete. |
| Evidence | A photo, voice note, drawing, bill or measurement that supports a claim. |
| Golden set | Cases with known correct answers used to score the agent. |
| Human in the loop | A step where a person reviews and approves the agent's work. |
| Optical Character Recognition | Technology that reads text from images or scans. |
| Speech to text | Converting spoken audio into written text. |
| Progressive Web App | A web app that can be installed on a phone and works offline. |
| Prompt injection | Hidden instructions in a document that try to mislead an AI system. |
| Tenant separation | Keeping each company's data completely isolated from others. |
| Certified quantity | A quantity the client has formally approved for payment. |
| Variation | Work that is different from, or in addition to, the original contract scope. |
| Advance recovery | Gradual deduction of an advance payment from later claims. |
| Entitlement | Whether a contractor has the right to payment for certain work under the contract. The agent only flags it. |
| Calculation trace | The recorded steps, inputs and rules that explain a calculated figure. |
| Idempotent upload | An upload that has the same result no matter how many times it is repeated. |
| Content fingerprint | A short value calculated from a file so identical files can be recognised. |
| Regression evaluation | A test that checks a new version is not worse than the approved one. |
| Recovery point objective | The most data, measured in time, that can be lost in a disaster. |
| Recovery time objective | The longest time allowed to restore service after a disaster. |
